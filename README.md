# 마법의 소라고동

스폰지밥의 "마법의 소라고동"을 흉내 낸 웹 앱입니다.

1. 질문을 입력합니다.
2. 소라고동 아래의 노란 고리를 잡고 멀리 당긴 뒤 놓습니다.
3. 줄이 딸깍딸깍 감겨 들어가고, 소라고동이 대답합니다.

대답은 질문 내용에 따라 달라집니다.

| 질문 종류 | 예시 | 나올 수 있는 대답 |
| --- | --- | --- |
| 예/아니오 | 오늘 놀러 가도 돼? | 그래, 안 돼, 다시 한번 물어봐, 언젠가는 |
| 고르기 | 피자 아니면 햄버거? | 둘 다 안 돼, 아무것도 하지 마, 다시 한번 물어봐 |
| 뭐/어떻게 | 이제 뭐 하지? | 아무것도 하지 마, 가만히 있어, 다시 한번 물어봐 |
| 누구 | 누가 이길까? | 아무도, 다시 한번 물어봐 |
| 어디 | 어디로 갈까? | 아무 데도 가지 마, 다시 한번 물어봐 |
| 언제 | 언제 운전면허 딸 수 있어? | 언젠가는, 지금은 안 돼, 다시 한번 물어봐 |
| 왜 | 왜 안 돼? | 그냥, 다시 한번 물어봐 |

같은 질문에 "다시 한번 물어봐"가 두 번 연속으로 나오지는 않습니다.

## 실행

빌드 과정이 없는 정적 페이지입니다. `index.html`을 브라우저로 열거나 아무 정적 서버로 띄우면 됩니다.

```sh
python3 -m http.server 8000
# http://localhost:8000
```

키보드로는 고리에 포커스를 두고 Enter/Space를 누르면 자동으로 당겼다 놓습니다. 소리(줄 감기는 소리, 음성 대답)는 아래 버튼으로 끌 수 있습니다.
